# Sorriso Claro Odontologia

Site de página única para clínica odontológica, com tratamentos, unidades e agendamento de avaliação pelo WhatsApp.

🔗 **[Ver no ar](https://ravena-web-design-oficial.netlify.app/demos/clinica-sorriso-claro)**

![Página inicial do site da clínica Sorriso Claro](preview.png)

## Funcionalidades

- Layout responsivo (celular, tablet e desktop)
- Lista de tratamentos
- Duas unidades com endereço e localização
- Botão de agendamento que abre a conversa no WhatsApp
- Meta tags para SEO e compartilhamento em redes sociais

## Tecnologias

HTML5 · CSS3 · JavaScript

CSS escrito à mão, sem framework. Página única, sem dependências externas.

## Sobre o projeto

Projeto demonstrativo com negócio fictício, criado do zero: layout, código e deploy.
